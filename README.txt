🏭 Paint Line Control 
📌 Суть проекта
Система управления 4-зонной линией покраски (подготовка → грунт → покраска → сушка) с координирующим мастером и профессиональной защитой.
🏗 Архитектура (3 уровня)
HMI → PLC_PRG (MUX) → FB_MasterManager → FB_Zone1..4 → Физика
PLC_PRG — диспетчер (коммутация MANUAL/AUTO, HMI watchdog)
FB_MasterManager — координация зон, конвейер, диагностика
FB_Zone1-4 — локальная логика каждой зоны


🎮 Режимы работы
AUTO — полный автоматический цикл по рецепту
MANUAL — ручное управление (только в Idle, без аварий)
Stop — graceful shutdown (доделать и остановиться)
E-Stop — немедленная остановка всего


🛡 Приоритеты защит (сверху вниз)
E-Stop / FireAlarm — рубит всё немедленно
Физические защиты (перегрев, давление, RobotFault)
MANUAL — ручное управление
AUTO — автоматика


🛡 Defense in Depth (защита на каждом уровне)
Зоны — Fail-Safe ELSE + Watchdog (30 сек)
Мастер — Fail-Safe ELSE + Watchdog (60 сек)
PLC_PRG — HMI Watchdog (2 сек) + MUX логика


🔍 Диагностика
ActiveError — текущая ошибка с приоритетами (ENUM)
История аварий — массив на 10 последних уникальных ошибок
Разделение Fault/Warning — Fault защёлкивается, Warning сбрасывается


📦 Ключевые принципы
✅ Инкапсуляция — VAR_INPUT не модифицируется
✅ Fail-Safe — при сбое переход в безопасное состояние
✅ Разделение ответственности — FB не знает про HMI
✅ Шаблон 6 шагов — везде (Init → Входы → Диагностика → CASE → FB → Выходы)
✅ E-Stop всегда главный — не обсуждается


🔑 Особенности
MANUAL не блокируется защёлкнутыми ошибками (можно тестировать после устранения)
HMI Watchdog отключает только MANUAL, AUTO продолжает работать
Graceful Stop — деталь дорабатывается, не бросается на полпути
Retain — счётчик деталей сохраняется при сбое питания


Стандарты: IEC 61131-3, PackML, Defense in Depth
